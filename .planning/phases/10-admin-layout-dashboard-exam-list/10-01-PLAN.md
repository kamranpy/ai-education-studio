## Objective

Redesign the Institute Admin portal shell (layout, sidebar, topbar) and primary pages (dashboard, exam list) to match the v2.0 design system. The admin layout must mirror the structural pattern of `student-layout.tsx` while adding admin-specific nav items and an institute name badge. ## Key Constraints

1. **CSS variables only** — use `var(--portal-*)` / `var(--brand-*)`, never hardcode hex
2. **Preserve all existing logic** — Wayfinder routes, router.get filters, publish/unpublish dialogs, pagination
3. **`portal-card` utility class** — use for all card surfaces
4. **No new dependencies** — use existing Radix UI components from `@/components/ui/*`
5. **Responsive** — sidebar hidden on mobile, drawer on hamburger click
6. **Dark mode** — CSS variables handle both themes automatically

3. Exam list renders as card grid with filters, empty state, and pagination

5. No hardcoded hex colors — all via CSS variables
