Create a scheduled job that automatically submits an exam attempt if the timer expires and the student hasn't submitted it manually (e.g., they closed their browser tab).

<task type="auto">
  <name>Task 1: Submit Expired Exams Command</name>
  <files>app/Console/Commands/SubmitExpiredExams.php, routes/console.php</files>
  <action>
Create artisan command `app:submit-expired-exams`.
- Query `ExamAttempt` where `status` is 'in_progress'.
- Join/Eager-load `Exam` to get `time_limit_minutes`.
- Check if `now()` is greater than `started_at` + `time_limit_minutes` + a grace period (e.g. 5 mins).
- Update the matching attempts to set `status = 'submitted'` and `submitted_at = now()`.
- Register the command in `routes/console.php` to run every minute (`->everyMinute()`). (per D-04: Auto-submit server-side).
  </action>
