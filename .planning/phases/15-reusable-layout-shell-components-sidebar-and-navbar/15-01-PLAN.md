# Plan 15-01: Layout Shell Unification

## Objective

Refactor all three portal layout files (`student-layout.tsx`, `admin-layout.tsx`, `super-admin-layout.tsx`) to use identical structure, the `react-material-symbols` icon library, pure Tailwind v4 CSS variable shorthand classes, and a unified mobile drawer. No shared wrapper component — each layout file remains separate.

- **Research:** `.planning/phases/15-reusable-layout-shell-components-sidebar-and-navbar/15-RESEARCH.md`
- **Requirements:** DS-04 (shared shell pattern), DS-05 (Student portal as canonical reference)

- `resources/js/app.tsx` — add icon CSS import

### Task 2: Remove Google Fonts Material Symbols from Blade template

**File:** `resources/views/app.blade.php`

**Action:** Remove line 42 (the Material Symbols Google Fonts `<link>` tag):
```html
<!-- DELETE this line: -->
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:wght,FILL@100..700,0..1&display=swap" rel="stylesheet" />
```

**Why:** `react-material-symbols/rounded` loads its own font via the npm package CSS. The Google Fonts link causes a redundant network request and can cause icon flash on first load.

**Verification:** `app.blade.php` no longer contains `Material+Symbols+Outlined`.

### Task 3: Refactor `student-layout.tsx`

**File:** `resources/js/layouts/student-layout.tsx`

**Action:** Full refactor. Replace all custom inline SVG icon components and all `style={{}}` color/background props.

**Specific changes:**

1. **Remove** all custom SVG icon functions: `DashboardIcon`, `AnalyticsIcon`, `SettingsIcon`, `LogoutIcon`, `BellIcon`, `MenuIcon`, `CloseIcon`

2. **Add** import at top:
   ```tsx
   import { MaterialSymbol } from 'react-material-symbols';
   ```

3. **Replace** icon usages:
   - `<DashboardIcon />` → `<MaterialSymbol icon="dashboard" size={20} />`
   - `<AnalyticsIcon />` → `<MaterialSymbol icon="bar_chart" size={20} />`
   - `<SettingsIcon />` → `<MaterialSymbol icon="settings" size={20} />`
   - `<LogoutIcon />` → `<MaterialSymbol icon="logout" size={20} />`
   - `<BellIcon />` → `<MaterialSymbol icon="notifications" size={20} />`
   - `<MenuIcon />` → `<MaterialSymbol icon="menu" size={24} />`
   - `<CloseIcon />` → `<MaterialSymbol icon="close" size={24} />`

4. **Convert** all `style={{}}` color/background props to Tailwind v4 CSS var shorthand. Pattern:

   | Old `style={{}}` | New `className` |
   |---|---|
   | `style={{ backgroundColor: 'var(--portal-sidebar-bg)' }}` | `className="bg-(--portal-sidebar-bg)"` |
   | `style={{ borderRight: '1px solid var(--portal-card-border)' }}` | `className="border-r border-(--portal-card-border)"` |
   | `style={{ backgroundColor: 'var(--portal-topbar-bg)', backdropFilter: 'blur(20px)', WebkitBackdropFilter: 'blur(20px)', borderBottom: '1px solid var(--portal-card-border)' }}` | `className="bg-(--portal-topbar-bg) backdrop-blur-xl border-b border-(--portal-card-border)"` |
   | `style={{ color: 'var(--portal-text-secondary)' }}` | `className="text-(--portal-text-secondary)"` |
   | `style={{ color: 'var(--portal-text-muted)' }}` | `className="text-(--portal-text-muted)"` |
   | `style={{ color: 'var(--portal-text-primary)' }}` | `className="text-(--portal-text-primary)"` |
   | `style={{ color: 'var(--portal-nav-text)' }}` | `className="text-(--portal-nav-text)"` |
   | `style={{ color: 'var(--brand-primary)' }}` | `className="text-brand-primary"` *(in @theme)* |
   | `style={{ color: 'var(--brand-error)' }}` | `className="text-brand-error"` *(in @theme)* |
   | `style={{ backgroundColor: 'rgba(255, 180, 171, 0.1)' }}` hover | `className="hover:bg-red-500/10"` |

5. **Convert** `onMouseEnter`/`onMouseLeave` JS hover handlers → Tailwind `hover:` classes:
   - Remove all `onMouseEnter`/`onMouseLeave` props from nav `<Link>` elements
   - Add `hover:bg-(--portal-nav-hover-bg)` to the inactive state className

6. **Nav active state** — replace inline `style` with conditional className:
   ```tsx
   // Active
   className="flex items-center gap-3 px-4 py-3 rounded-r-full transition-all duration-200 bg-(--portal-nav-active-bg) text-(--portal-nav-active-text) border-l-4 border-(--portal-nav-active-border)"
   // Inactive
   className="flex items-center gap-3 px-4 py-3 rounded-r-full transition-all duration-200 text-(--portal-nav-text) hover:bg-(--portal-nav-hover-bg)"
   ```

7. **Convert** `UserAvatar` component to pure Tailwind:
   ```tsx
   function UserAvatar({ user, size = 'md' }: { user: User; size?: 'sm' | 'md' }) {
       const sizeClasses = size === 'sm' ? 'w-8 h-8 text-xs' : 'w-10 h-10 text-sm';
       return (
           <div className={`${sizeClasses} rounded-full flex items-center justify-center font-bold text-white shrink-0 bg-linear-to-br from-indigo-500 to-violet-600 ring-2 ring-white/20`}>
               {getInitials(user.name)}
           </div>
       );
   }
   ```

8. **Mobile overlay** — replace `style={{ backgroundColor: 'rgba(0,0,0,0.6)' }}` with `className="bg-black/60"`

9. **Mobile drawer** — replace inline `transform` style with Tailwind:
   ```tsx
   className={`md:hidden fixed left-0 top-0 h-screen flex flex-col py-8 z-50 transition-transform duration-300 w-[280px] bg-(--portal-sidebar-bg) border-r border-(--portal-card-border) ${mobileOpen ? 'translate-x-0' : '-translate-x-full'}`}
   ```

10. **Root wrapper** — replace `style={{ backgroundColor: 'var(--portal-bg)', fontFamily: 'Inter, sans-serif' }}`:
    ```tsx
    className="min-h-screen bg-(--portal-bg) font-sans"
    ```

**Verification:** No `style={{` containing color/background values remains in the file. No custom SVG icon components exist. No `onMouseEnter`/`onMouseLeave` handlers on nav items.

## Acceptance Criteria

1. **DS-04** — All three portal layouts (`student-layout.tsx`, `admin-layout.tsx`, `super-admin-layout.tsx`) use identical structural patterns for sidebar, topbar, mobile drawer, avatar, and nav item rendering
2. **DS-05** — The `MaterialSymbol` component from `react-material-symbols` is used for all icons in all three layouts; no custom SVG components, no font `<span>` elements, no Lucide imports in layout files
3. No `style={{}}` props containing color, background, or border values remain in any layout file
4. No `dark:` Tailwind variant classes remain in any layout file (CSS vars handle theming)
5. No `onMouseEnter`/`onMouseLeave` handlers for hover colors on nav items
6. Super Admin breakpoint unified to `md:` (was `lg:`)
7. Google Fonts Material Symbols link removed from `app.blade.php`
8. `npm run build` and `npm run types:check` both pass

## Threat Model

This phase is a pure frontend refactor with no backend changes, no new routes, no authentication changes, and no data handling. No security threats introduced. The removal of `ui-avatars.com` is a **security improvement** — eliminates an external request that sends the user's name to a third-party service.
