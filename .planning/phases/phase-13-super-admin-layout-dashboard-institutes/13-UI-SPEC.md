### 2. Super Admin Dashboard (`pages/SuperAdmin/Dashboard.tsx`)

**Page Layout:**
- Header: "Dashboard" with period selector (Last 7 days, 30 days, 90 days)
- Grid: 4-column stats row, then 2-column charts

**Stats Cards (4-up grid, gap-6):**
| Metric | Icon | Format |
|--------|------|--------|
| Total Institutes | Building2 | {count} |
| Total Exams | ClipboardList | {count} |
| Total Revenue | TrendingUp | ${amount} |
| Credits Sold | CreditCard | {count} |

**Card Style:**
```
<Card>
  <CardHeader className="flex flex-row items-center justify-between pb-2">
    <CardTitle className="text-sm font-medium">{title}</CardTitle>
    <Icon className="h-4 w-4 text-muted-foreground" />
  </CardHeader>
  <CardContent>
    <div className="text-2xl font-bold">{value}</div>
    <p className="text-xs text-muted-foreground">
      {trend} from last period
    </p>
  </CardContent>
</Card>
```

**Charts Section (2-column grid):**
1. **Exams Over Time** - BarChart or LineChart
   - X-axis: dates
   - Y-axis: count
   - Color: indigo

2. **Revenue Over Time** - AreaChart or LineChart
   - X-axis: dates
   - Y-axis: revenue ($)
   - Color: purple

**Chart Container:**
- Height: 300px (h-[300px])
- Card wrapper with header
- ResponsiveContainer from recharts

### 3. Institutes Management (`pages/SuperAdmin/Institutes/Index.tsx`)

**Page Layout:**
- Header: "Institutes" + Add Institute button (right-aligned)
- Filter bar: Search + Status filter + Sort
- Data table with pagination

**Header Section:**
```
<div className="flex items-center justify-between">
  <h1 className="text-2xl font-semibold">Institutes</h1>
  <Button>
    <Plus className="mr-2 h-4 w-4" />
    Add Institute
  </Button>
</div>
```

**Filter Bar:**
- Search input: "Search by name or email..." (w-96)
- Status filter dropdown: All, Active, Suspended, Pending
- Sort dropdown: Name, Created Date, Last Active

**Table Columns:**
| Column | Width | Content |
|--------|-------|---------|
| Name | flex | Institute name + admin email |
| Status | 120px | Badge (Active/Suspended/Pending) |
| Created | 120px | Date |
| Exams | 80px | Count |
| Revenue | 100px | $ amount |
| Actions | 80px | Dropdown menu |

**Row Style:**
- Border-b between rows
- Hover: `hover:bg-zinc-50 dark:hover:bg-zinc-800/50`

**Status Badge Variants:**
- Active: `bg-green-100 text-green-700 dark:bg-green-900/30 dark:text-green-400`
- Suspended: `bg-red-100 text-red-700 dark:bg-red-900/30 dark:text-red-400`
- Pending: `bg-amber-100 text-amber-700 dark:bg-amber-900/30 dark:text-amber-400`

**Actions Dropdown:**
- View Details → Link to institute detail
- Edit → Opens edit modal/page
- Suspend/Activate → Status toggle with confirmation

**Empty State:**
- Icon: Building2 (size-12, muted)
- Text: "No institutes found"
- Subtext: "Try adjusting filters or add a new institute"

## Interaction Patterns

### Navigation
- Click nav item → navigate with Inertia Link
- Active state updates on route change
- Mobile: Sheet closes after navigation

### Dashboard
- Period selector triggers data refresh
- Charts animate on data change
- Stat cards show loading skeleton during fetch

### Institutes Table
- Search debounced (300ms)
- Pagination: 10/25/50 per page
- Sortable columns with click
- Bulk actions (future): checkbox selection
