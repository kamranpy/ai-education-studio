# Phase 04.1: Exam Creation Enhancements & Evaluation Settings - Plan

## Goal
Enhance the Exam Builder UI with tabs, add class/subject fields, introduce flexible result release strategies (per-exam), and improve the student exam experience with separated question types and a dedicated results history.

## Tasks

<task>
<name>Create Migrations for Exams and Exam Attempts</name>
<description>Create new migrations to add required columns to `exams` and `exam_attempts` tables.</description>
<read_first>
- database/migrations/2026_xxxx_create_exams_table.php (if exists, to understand structure)
</read_first>
<action>
Generate and write a new migration file: `php artisan make:migration add_details_and_evaluation_to_exams_table --table=exams`.
Inside the migration `up` method, add:
`$table->string('class_name')->nullable();`
`$table->string('subject_name')->nullable();`
`$table->enum('evaluation_strategy', ['instant', 'manual'])->default('instant');`
`$table->timestamp('results_announced_at')->nullable();`

Generate and write a new migration file: `php artisan make:migration add_section_submissions_to_exam_attempts_table --table=exam_attempts`.
Inside the migration `up` method, add:
`$table->timestamp('tf_submitted_at')->nullable();`
`$table->timestamp('mcqs_submitted_at')->nullable();`
`$table->timestamp('written_submitted_at')->nullable();`

Update the `Exam` model (`app/Models/Exam.php`) to include these new fields in the `$fillable` array and cast `results_announced_at` to `datetime`.
Update the `ExamAttempt` model (`app/Models/ExamAttempt.php`) to include the submission fields in `$fillable` and cast them to `datetime`.
</action>
<acceptance_criteria>
- The migration files exist in `database/migrations/`
- Running `php artisan migrate:status` shows the new migrations
- `app/Models/Exam.php` fillable array includes `class_name`, `subject_name`, `evaluation_strategy`, `results_announced_at`
- `app/Models/ExamAttempt.php` fillable array includes `tf_submitted_at`, `mcqs_submitted_at`, `written_submitted_at`
</acceptance_criteria>
</task>

Add a "Submit [Type] Section" button within each tab.

</action>
