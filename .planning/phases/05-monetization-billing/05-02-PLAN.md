# Phase 5: Monetization & Billing
## Plan 05-02: Stripe Setup & Admin Top-Up UI

### Requirements
- BILL-01: Institute Admin can purchase exam credits

### Description
Install `stripe/stripe-php`, create the necessary backend controller to initiate dynamic Stripe Checkout Sessions, and build the React UI for Institute Admins to view their balance and purchase credit packages.

---

### Tasks

<task>
<id>05-02-01</id>
<title>Install Stripe PHP SDK</title>
<read_first>
- composer.json
</read_first>
<action>
1. Run `composer require stripe/stripe-php`.
2. Add `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET` to `.env.example` with placeholder values.
</action>
<acceptance_criteria>
- `composer.json` contains `stripe/stripe-php`.
- `.env.example` contains `STRIPE_SECRET_KEY=` and `STRIPE_WEBHOOK_SECRET=`.
</acceptance_criteria>
</task>

<task>
<id>05-02-02</id>
<title>Create BillingController and Routes</title>
<read_first>
- routes/web.php
- app/Models/CreditPackage.php
</read_first>
<action>
1. Create `app/Http/Controllers/Institute/BillingController.php`.
2. Implement `index()` method:
   - Fetch all active `CreditPackage` records.
   - Return an Inertia view `Admin/Billing/Index` passing the packages and `$request->user()->institute->credits`.
3. Implement `checkout(Request $request)` method:
   - Validate `package_id` exists in `credit_packages`.
   - Set Stripe API key: `\Stripe\Stripe::setApiKey(config('services.stripe.secret'));`.
   - Create a `\Stripe\Checkout\Session` using the dynamic price data approach from `05-RESEARCH.md`.
   - `metadata` MUST include `institute_id` and `package_id`.
   - Return an Inertia location redirect to `$session->url`.
4. In `routes/web.php`:
   - Inside the existing `auth`, `EnsureInstituteAdmin` middleware group (where `/admin/exams` lives), add:
     - `Route::get('/admin/billing', [BillingController::class, 'index'])->name('admin.billing.index');`
     - `Route::post('/admin/billing/checkout', [BillingController::class, 'checkout'])->name('admin.billing.checkout');`
     - `Route::get('/admin/billing/success', [BillingController::class, 'success'])->name('admin.billing.success');`
     - `Route::get('/admin/billing/cancel', [BillingController::class, 'cancel'])->name('admin.billing.cancel');`
5. In `config/services.php`, add a `stripe` array with `secret` and `webhook_secret`.
6. Run `php artisan wayfinder:generate` to update frontend routes.
</action>
<acceptance_criteria>
- `BillingController` exists with `index` and `checkout` methods using raw Stripe API.
- Routes are registered under `/admin/billing`.
- `wayfinder` outputs the new routes.
</acceptance_criteria>
</task>
