## Key Accomplishments

1. **Public homepage** — branded landing page with hero, features grid, pricing, testimonials, and FAQ sections
2. **Unified auth pages** — custom login, register, forgot/reset password, verify email, confirm password, and 2FA pages
3. **Student portal** — full redesign of layout shell, dashboard, exam list, exam-taking screen, results, history, interstitial, and pending pages
4. **Admin portal** — full redesign of layout shell, dashboard, exam list, exam builder, exam detail, attempts list/detail, users, invite, and billing pages
5. **Super Admin portal** — full redesign of layout shell, global analytics dashboard, institutes management, LLM settings, Stripe settings, and credit package pages
6. **Shared layout shell** — unified sidebar/navbar shell across all three portals using `@material-symbols-svg/react`, CSS variable theming, unified mobile drawer, and gradient avatar
