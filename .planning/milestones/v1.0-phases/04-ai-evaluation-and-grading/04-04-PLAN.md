# Phase 4 - Plan 4: Student Exam Results

## Goal
Show the student their graded results if `graded`, or an interstitial loading page while `grading`.

## Requirements
- AIEV-05 (Students view results, but AI explanation is hidden)

## Tasks

<task>
  <objective>Student Results Routing & Controller</objective>
  <read_first>
    - routes/web.php
    - app/Http/Controllers/Student/ExamAttemptController.php
  </read_first>
  <action>
    In `routes/web.php` for students:
    `GET /student/exams/{exam}/attempts/{attempt}/results` -> `student.exams.results` mapped to `ExamAttemptController@results`.
    If attempt `status` is `grading`, it should return `interstitial.tsx` (Interstitial Loading Page).
    If attempt `status` is `graded` or `needs_review`, it returns `results.tsx`.
  </action>
  <acceptance_criteria>
    - `routes/web.php` defines student results route
    - `app/Http/Controllers/Student/ExamAttemptController.php` exposes `results` method returning either view
  </acceptance_criteria>
</task>

<task>
  <objective>Build Interstitial (Grading) UI</objective>
  <read_first>
    - .planning/phases/04-ai-evaluation-and-grading/04-UI-SPEC.md
  </read_first>
  <action>
    Create `resources/js/pages/student/exams/interstitial.tsx`.
    Show heading `Exam submitted`.
    Include an Inertia polling mechanism: `useInterval` or `setTimeout` that runs `router.reload({ only: ['attempt'] })` every 5 seconds until the attempt status resolves. The UI matches Surface 6 in the spec.
  </action>
  <acceptance_criteria>
    - `resources/js/pages/student/exams/interstitial.tsx` exists and uses `router.reload`
  </acceptance_criteria>
</task>

<task>
  <objective>Build Student Results UI</objective>
  <read_first>
    - .planning/phases/04-ai-evaluation-and-grading/04-UI-SPEC.md
  </read_first>
  <action>

    If `status === 'needs_review'`, show banner "Your exam is being reviewed...".

    As per D-25: DO NOT show AI explanation to the student.
  </action>
  <acceptance_criteria>
    - `resources/js/pages/student/exams/results.tsx` exists
    - `resources/js/pages/student/exams/results.tsx` does NOT contain AI explanation strings or variables
