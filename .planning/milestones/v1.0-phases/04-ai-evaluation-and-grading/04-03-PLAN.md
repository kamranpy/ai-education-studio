# Phase 4 - Plan 3: Institute-Admin Attempt UI & Grading Override

## Goal
Build the Institute-Admin views to list student attempts, drill down into an attempt, see AI reasoning/scores, and apply manual overrides.

## Requirements
- AIEV-04
- AIEV-05

## Tasks

<task>
  <objective>Institute-Admin Controllers & Routing</objective>
  <read_first>
    - routes/web.php
  </read_first>
  <action>
    In `routes/web.php`, inside the `EnsureInstituteAdmin` grouped middleware:
    `GET  /admin/exams/{exam}/attempts` -> `ExamAttemptAdminController@index`
    `GET  /admin/exams/{exam}/attempts/export` -> `ExamAttemptAdminController@export` (Streamed CSV download of candidates and results)
    `GET  /admin/exams/{exam}/attempts/{attempt}` -> `ExamAttemptAdminController@show`
    `POST /admin/exams/{exam}/attempts/{attempt}/override` -> `ExamAttemptAdminController@override` (Process manual override to `override_score` and log audit trace in `exam_attempt_answer_overrides`)
    `POST /admin/exams/{exam}/attempts/{attempt}/mark-reviewed` -> `ExamAttemptAdminController@markReviewed` (Flip `needs_review` to `graded` without overriding)
    Create `ExamAttemptAdminController.php`. Implement logic to load the attempts securely via tenant scopes.
  </action>
  <acceptance_criteria>
    - `routes/web.php` contains the attempts routes including `export`
    - `app/Http/Controllers/Admin/ExamAttemptAdminController.php` exists and enforces tenant logic
  </acceptance_criteria>
</task>
