# Phase 4 - Plan 2: Super-Admin LLM Configuration

## Goal
Build the global LLM Settings UI for Super-Admins to configure the active AI provider, including the "Test connection" endpoint.

## Requirements
- AIEV-01

  <read_first>
    - routes/web.php

    - .planning/phases/04-ai-evaluation-and-grading/04-CONTEXT.md
  </read_first>
  <action>
    In `routes/web.php`, add endpoints for `/super-admin/llm` within a Super-Admin middleware group (if it doesn't already exist, create `EnsureSuperAdmin` middleware).
    `GET /super-admin/llm` -> `LlmSettingController@index`
    `POST /super-admin/llm` -> `LlmSettingController@store` (save settings)
    `POST /super-admin/llm/test` -> `LlmSettingController@testConnection` (run a 1 token test with submitted details using Prism)

    In `LlmSettingController@index`, pass down existing active LLM settings. For security, `api_key` if set MUST NOT be passed back in plaintext. Send a placeholder or boolean to indicate it is set. If saving, make sure to deactivate other `is_active` records in a transaction.
  </action>
  <acceptance_criteria>
    - `routes/web.php` contains `/super-admin/llm` routes
    - `app/Http/Controllers/SuperAdmin/LlmSettingController.php` exists with `index`, `store`, `testConnection` methods
  </acceptance_criteria>
</task>
