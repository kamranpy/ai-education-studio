# Phase 5: Monetization & Billing
## Plan 05-03: Stripe Webhook Handler

### Requirements
- BILL-01: Institute Admin can purchase exam credits

### Description
Implement a secure webhook listener for Stripe's `checkout.session.completed` event. This handler validates the webhook signature, guarantees idempotency to prevent double-crediting, and atomically updates the institute's credit balance.

---

### Tasks

<task>
<id>05-03-01</id>
<title>Create StripeWebhookController</title>
<read_first>
- app/Models/Transaction.php
- app/Models/Institute.php
</read_first>
<action>
1. Create `app/Http/Controllers/StripeWebhookController.php`.
2. Implement `handle(Request $request)`:
   - Extract the payload and `Stripe-Signature` header.
   - Use `\Stripe\Webhook::constructEvent($payload, $sigHeader, config('services.stripe.webhook_secret'))`.
   - Wrap in a `try/catch` for `SignatureVerificationException` and return a 400 response on failure.
   - If `$event->type === 'checkout.session.completed'`:
     - Extract `$session = $event->data->object;`.
     - Check idempotency: `if (Transaction::where('stripe_session_id', $session->id)->exists()) { return response('Already processed', 200); }`
     - Wrap in `DB::transaction()`:
       - Find the `Institute` using `$session->metadata->institute_id`.
       - `increment('credits', $session->metadata->credits)`.
       - Create a `Transaction` record with the session ID, amount, and credits added.
   - Return a 200 response to acknowledge receipt.
</action>
<acceptance_criteria>
- `StripeWebhookController.php` exists and verifies signature using `\Stripe\Webhook::constructEvent`.
- Credits are incremented and `Transaction` is logged inside a `DB::transaction`.
- Exits early with 200 if `stripe_session_id` is already in the database.
</acceptance_criteria>
</task>

<action>
1. In `routes/web.php`, add an unprotected route (outside any auth middleware):

2. In `bootstrap/app.php`, within the `withMiddleware` closure:
   - Add `$middleware->validateCsrfTokens(except: ['stripe/webhook']);` to prevent Laravel from blocking the webhook POST request.
</action>

- `bootstrap/app.php` excludes `stripe/webhook` from CSRF validation.
</acceptance_criteria>
