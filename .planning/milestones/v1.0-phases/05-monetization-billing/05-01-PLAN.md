# Phase 5: Monetization & Billing
## Plan 05-01: Database Models & Migrations

### Requirements
- BILL-01: Institute Admin can purchase exam credits
- TENT-01: System isolates database records per institute (tenant)

### Description
Create the fundamental database structures for the monetization system. We need to track the `credits` balance on the `institutes` table, define `CreditPackage` models (which Super Admins can configure), and create a `transactions` table to serve as an audit log and provide idempotency for Stripe webhooks.
