# Phase 5: Monetization & Billing
## Plan 05-04: Exam Start Credit Deduction & Blocking

### Requirements
- BILL-02: System deducts credits per student exam attempt before allowing the exam to start
- BILL-03: System prevents exam starts if the institute has insufficient credits

### Description
Implement the core billing logic to deduct credits atomically when a student starts an exam. If an institute has no credits left, students will be blocked with an error message. Institute Admins will see a warning banner if their balance is zero.

<task>
<id>05-04-01</id>
<title>Atomic Credit Deduction at Exam Start</title>
<read_first>
- app/Http/Controllers/Student/ExamAttemptController.php
- app/Models/Institute.php
</read_first>
<action>
1. In `app/Http/Controllers/Student/ExamAttemptController.php`, update the `store` method.
2. After checking for an existing attempt (which is free to resume) and before creating a new `ExamAttempt`:
   - Identify the user's institute ID (e.g., `$user->institute_id`).
   - Wrap the credit check and deduction in a `DB::transaction()`:
     - Fetch the institute with a pessimistic lock: `$institute = Institute::where('id', $user->institute_id)->lockForUpdate()->first();`.
     - If `$institute->credits <= 0`, abort with a 403 or redirect back with a specific error message: "Your institute does not have enough credits to start this exam."
     - Deduct the credit: `$institute->decrement('credits', 1);`.
     - Create the `ExamAttempt` record inside the same transaction.
</action>
<acceptance_criteria>
- Resuming an `in_progress` exam does not deduct a credit.
- Creating a new exam attempt decrements the institute's credits by 1.
- If credits are 0, creating a new attempt fails gracefully.
- The `lockForUpdate()` method is used inside a `DB::transaction()`.
</acceptance_criteria>
</task>

#### step_by_step
1. Open Tinker and set your institute's credits to 0.
2. Login as a student and try to start a new exam. Verify it shows the "not enough credits" message.
3. Login as the Institute Admin and go to the Exams list. Verify the warning banner is visible.
4. Open Tinker and set credits to 1.
5. Login as a student and start a new exam. Verify the exam starts.
6. Open Tinker and verify credits are now 0.
7. Refresh the exam page as the student. Verify the exam resumes without error.
