<task type="auto">
  <name>Task 1: Controller Show Method (One Question)</name>
  <files>app/Http/Controllers/Student/ExamAttemptController.php, routes/web.php</files>
  <action>
Implement `ExamAttemptController@show(Exam $exam, ExamAttempt $attempt)`.
- Enforce the attempt belongs to user and is `in_progress`.
- Accept a `?q=` parameter indicating the index in `question_order`. Default to 0.
- Retrieve the specific question ID from the `question_order` array.
- Load the Question model and its options (if applicable).
- Look up if an `ExamAttemptAnswer` already exists for this question to pre-fill.
- Return an Inertia view `Student/ExamTake` with the current question, index, total count, existing answer, and the exam's time limit.
  </action>
  <verify>
    <automated>php artisan test --filter ExamAttemptController</automated>
  </verify>
  <done>Backend serves single questions based on JSON array index.</done>
</task>

<task type="auto">
  <name>Task 2: Exam Take UI</name>
  <files>resources/js/pages/Student/ExamTake.tsx</files>
  <action>
Create the `ExamTake` React component using Shadcn UI. (per D-01: Render one question at a time).
- Display the question text prominently.
- Render the correct input type based on question type (Radio buttons for MC/TF, Textarea for Written).
- Provide "Previous" and "Next" buttons to cycle through the indices.
- On "Next" or "Previous", dispatch an Inertia PUT request to save the current answer (using `preserveState: true` and `preserveScroll: true`). (per D-02: Save on blur/navigation).
  </action>
  <verify>
    <automated>npm run lint</automated>
  </verify>
  <done>UI allows answering and navigating questions cleanly.</done>
</task>

<task type="auto">
  <name>Task 3: Save Answer & Submit</name>
  <files>app/Http/Controllers/Student/ExamAttemptController.php</files>
  <action>
Implement `ExamAttemptController@update(Request, Exam, ExamAttempt)`:
- Accept `question_id`, `answer_data` (polymorphic JSON), and `action` ('save' or 'submit').
- Validate that the question belongs to the exam.
- Update or create the `ExamAttemptAnswer` for this attempt.
- If `action === 'submit'`, change attempt status to `submitted` and `submitted_at = now()`. Redirect to a conclusion/dashboard page (per TAKE-07).
- Otherwise, redirect to the new question index.
  </action>
  <verify>
    <automated>php artisan test --filter ExamAttemptController</automated>
  </verify>
  <done>Student can auto-save and finally submit their exam.</done>
</task>
