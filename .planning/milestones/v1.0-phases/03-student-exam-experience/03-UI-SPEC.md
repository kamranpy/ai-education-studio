## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing (between question content) |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps (between question card and navigation controls) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: none

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | bg-background | Background, primary surfaces |
| Secondary (30%) | bg-muted / bg-card | Question cards, progress visualizers |
| Accent (10%) | bg-primary | Call to Action (Next Section, Submit Exam) |
| Destructive | bg-destructive | Timer expiry countdown, anti-cheat blurred overlay warnings |

Accent reserved for: Exam completion and primary pagination (Next/Submit) actions. Not for simple selection variants.
