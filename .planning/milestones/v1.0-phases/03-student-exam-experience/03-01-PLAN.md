<task type="auto">
  <name>Task 3: Starting the Exam</name>
  <files>app/Http/Controllers/Student/ExamAttemptController.php, routes/web.php</files>
  <action>
Create `ExamAttemptController@store` endpoint for students under `/student/exams/{exam}/attempts`.
When hitting this endpoint:
- Enforce the user belongs to the institute and the exam is published.
- Check if an attempt already exists (if 'in_progress', redirect to it).
- If new: shuffle the related question IDs of the exam.
- Create `ExamAttempt` with `question_order` = the shuffled array (per decision TAKE-05).
- Redirect to the `ExamAttemptController@show` route (which we will build in Plan 2).
  </action>
  <verify>
    <automated>php artisan test --filter ExamAttemptController || echo "MISSING - Wave 0 must create this test"</automated>
  </verify>
  <done>Student can start an exam and receive a randomized question array in DB.</done>
