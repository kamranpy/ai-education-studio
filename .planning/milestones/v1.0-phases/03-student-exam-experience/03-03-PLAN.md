<tasks>
<task type="auto">
  <name>Task 1: Exam Timer UI & Blur Tracking</name>
  <files>resources/js/pages/Student/ExamTake.tsx</files>
  <action>
In `ExamTake.tsx`:
- Render a live countdown timer calculating against `started_at` + `time_limit`. If it hits 0, auto-submit the exam (trigger the 'submit' action from Plan 2).
- Add a `visibilitychange` event listener on `document`. (per D-03).
- When `document.visibilityState === 'hidden'`, send an async fetch request (not Inertia, simple fetch so it doesn't interrupt page state) to `/student/exams/{exam}/attempts/track` with `{ event: 'blur', timestamp }`.
- When they return (`document.visibilityState === 'visible'`), display a full-screen or prominent Shadcn AlertDialog warning them that their actions have been recorded.
  </action>
  <verify>
    <automated>npm run lint</automated>
  </verify>
  <done>Timer counts down and tab blurring triggers tracking event and warning.</done>
</task>

<task type="auto">
  <name>Task 2: Tracking API Endpoint</name>
  <files>app/Http/Controllers/Student/ExamAttemptController.php, routes/web.php</files>
  <action>
Create `ExamAttemptController@logTracking(Request, Exam, ExamAttempt)`:
- Create POST route `/student/exams/{exam}/attempts/track`.
- Validate the event data.
- Append the decoded JSON event into the `tracking_logs` JSON array of the `ExamAttempt`. (Create array if null).
- Return 200 OK.
  </action>
  <verify>
    <automated>php artisan test --filter ExamAttemptController</automated>
  </verify>
  <done>Server successfully records blur events in the tracking_logs column.</done>
</task>

<task type="auto">
  <name>Task 3: Server Timer Verification</name>
  <files>app/Http/Controllers/Student/ExamAttemptController.php</files>
  <action>
In `ExamAttemptController@update` (from Plan 2):
- Before saving the answer, check `now() > ($attempt->started_at + $exam->time_limit_minutes)`. Include a small grace period (e.g., 30 seconds) for network lag.
- If expired, forcefully set status to `submitted` and ignore the answer if it's far past expiry, and redirect to conclusion.
  </action>
  <verify>
    <automated>php artisan test --filter ExamAttemptController</automated>
  </verify>
  <done>Server rejects answers submitted significantly after time has expired.</done>
</task>
