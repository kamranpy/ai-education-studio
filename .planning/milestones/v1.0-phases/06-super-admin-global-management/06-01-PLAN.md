<action>
Create a new migration file. Run `php artisan make:migration add_type_and_notes_to_transactions_table` to generate the file, then edit it to contain:

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::table('transactions', function (Blueprint $table) {
            $table->string('type')->default('stripe_purchase')->after('status');
            $table->text('notes')->nullable()->after('type');
            $table->index('type');
        });

        // Backfill existing rows that have no type set
        DB::table('transactions')->whereNull('type')->update(['type' => 'stripe_purchase']);
    }

    public function down(): void
    {
        Schema::table('transactions', function (Blueprint $table) {
            $table->dropIndex(['type']);
            $table->dropColumn(['type', 'notes']);
        });
    }
};
```

The `default('stripe_purchase')` ensures new rows created by the existing `StripeWebhookController` (which does not set `type`) will automatically get the correct value. The backfill `DB::table(...)->whereNull('type')` handles any rows inserted before the migration runs — though in practice the column is new so all existing rows will have `NULL` until the backfill runs.
</action>

<action>
Run `php artisan make:migration create_stripe_settings_table` then edit the generated file:

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('stripe_settings', function (Blueprint $table) {
            $table->id();
            $table->text('secret_key')->nullable();
            $table->text('webhook_secret')->nullable();
            $table->boolean('is_active')->default(false);
            $table->foreignUuid('updated_by')->nullable()->constrained('users')->nullOnDelete();
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('stripe_settings');
    }
};
```

Use `text` (not `string`) for `secret_key` and `webhook_secret` because Eloquent's `encrypted` cast produces ciphertext longer than 255 characters. The `foreignUuid` on `updated_by` references `users.id` (UUID primary key) and nulls on delete so the record is not lost if the super admin user is removed.
</action>

### Task 3: New Model — `app/Models/StripeSetting.php`

<read_first>
- `app/Http/Controllers/SuperAdmin/LlmSettingController.php` — see how `hasApiKey()`, `masked_api_key`, and `is_active` are used to understand the interface this model must expose
- `resources/js/pages/SuperAdmin/Llm.tsx` — see `has_api_key` / `masked_api_key` props pattern to mirror for Stripe keys
</read_first>

<action>
Create `app/Models/StripeSetting.php` with the following exact content:

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class StripeSetting extends Model
{
    protected $fillable = [
        'secret_key',
        'webhook_secret',
        'is_active',
        'updated_by',
    ];

    protected $hidden = [
        'secret_key',
        'webhook_secret',
    ];

    protected function casts(): array
    {
        return [
            'secret_key'     => 'encrypted',
            'webhook_secret' => 'encrypted',
            'is_active'      => 'boolean',
        ];
    }

    /**
     * Whether a secret key has been stored.
     */
    public function hasSecretKey(): bool
    {
        return ! empty($this->attributes['secret_key']);
    }

    /**
     * Whether a webhook secret has been stored.
     */
    public function hasWebhookSecret(): bool
    {
        return ! empty($this->attributes['webhook_secret']);
    }

    /**
     * Masked display value for the secret key (last 4 chars visible).
     */
    public function getMaskedSecretKeyAttribute(): ?string
    {
        if (! $this->hasSecretKey()) {
            return null;
        }

        return 'sk_•••' . substr($this->secret_key, -4);
    }

    /**
     * Masked display value for the webhook secret (last 4 chars visible).
     */
    public function getMaskedWebhookSecretAttribute(): ?string
    {
        if (! $this->hasWebhookSecret()) {
            return null;
        }

        return 'whsec_•••' . substr($this->webhook_secret, -4);
    }

    /**
     * The super admin who last updated these settings.
     */
    public function updatedBy(): BelongsTo
    {
        return $this->belongsTo(User::class, 'updated_by');
    }
}
```

Key design notes:
- `$hidden` prevents raw encrypted ciphertext from leaking into JSON serialization.
- `hasSecretKey()` / `hasWebhookSecret()` check `$this->attributes` (raw encrypted blob) rather than `$this->secret_key` (which would trigger decryption on every check).
- The `getMasked*Attribute()` accessors use `$this->secret_key` (decrypted) only when a value is confirmed to exist, so decryption only happens when needed.
- `casts()` method (not `$casts` property) matches the Laravel 13 / existing codebase convention seen in `Transaction.php` and `Institute.php`.
</action>
